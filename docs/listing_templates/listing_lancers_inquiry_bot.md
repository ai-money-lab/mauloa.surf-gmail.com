## 案件概要

LINE公式アカウントとWebサイトに対応したAI問い合わせ自動対応Botを構築します。

### こんなお悩みありませんか？
- 毎日同じ質問に何度も答えている
- 営業時間外の問い合わせを取りこぼしている
- 人手が足りず、お客様の返信が遅れがち
- チャットボットを検討したが、機械的な回答では不安

### 解決策
最新AI（Claude / Anthropic社）を搭載した自然な対話が可能な問い合わせBotを構築します。

**特徴:**
- LINE + Webチャットの2チャネル同時対応
- 業種特化のFAQナレッジベース（50問〜）を構築
- 対応できない問い合わせは担当者に自動エスカレーション
- 全問い合わせをGoogle Sheetsに自動記録
- n8nによるワークフロー自動化

### 対応業種
不動産、クリニック・歯科、美容サロン、飲食店、スクール・教室、その他サービス業

### 価格帯
- ライト（LINE のみ）: 10万円〜
- スタンダード（LINE + Web）: 20万円〜
- プレミアム（フル機能 + 3ヶ月サポート）: 30万円〜

### 納期
7〜14営業日（プランによる）
