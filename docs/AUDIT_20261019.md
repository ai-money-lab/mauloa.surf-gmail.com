## 8. `claude -p` バックエンドの実測メモ（2026-10-19）

`ANTHROPIC_DISABLED=1` の経路を `generate_and_post --dry-run` で実際に回して
分かったこと。`claude -p` は**コーディングエージェントのCLI**なので、
素のテキスト生成として使うには明示的に落とす必要がある。

| 観測した挙動 | 対処 |
|---|---|
| 「JSONのみ出力」と指示しても、前置き・前提の確認・「判断してほしいこと」付きの報告文を返す | `--system-prompt` で Claude Code のシステムプロンプトを置き換え、`generate_json` ではプロンプト末尾に出力形式の厳守を追記 |
| 指定した柱と違う柱で生成した（要求 柱1「家を売ったときの税金」→ 出力 柱4「中古マンションを買うとき」。`data/system_a/generated/2026-10-19_013211.json`） | 同上。放置すると ThemeRotator の重複回避と柱比率が意味を失う |
| リポジトリのファイルを読んだ内容（`post_history.json` の件数111・最終2026-06-23）を前提に回答した | `--restricted` で user/project/local の設定ファイルを無視 |
| 毎回 stdin を3秒待って警告を出す | `stdin=DEVNULL` |

対処後の実測: 柱番号を与えたプロンプトに対し、フェンスも前置きもない
`{"pillar": 1, "ok": true}` が返ることを確認。

**ただしパイプライン全体（生成 → FactCheck → QC → 選択）の完走は
この経路では未確認。** 課金なしで回したい場合は、依存するのは
`generate_json` が返す JSON のスキーマなので、採用前に
`--dry-run` で最後まで通ることを確認すること。
