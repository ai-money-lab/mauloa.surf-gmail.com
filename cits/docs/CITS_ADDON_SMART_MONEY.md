# CITS アドオン: スマートマネー追跡

## 概要
外国人投資家・機関投資家の売買動向を追跡し、
「スマートマネーの流れ」をアナリストチームの判断材料に加える。

## データソース

### 投資部門別売買動向（JPX公開データ）
- 外国人: 最も市場インパクトが大きい
- 信託銀行: 年金基金の動き
- 個人: 逆張り指標として利用
- 事業法人: 自社株買いの動向

### 空売り残高（JPX公開データ）
- 空売り比率の推移
- 個別銘柄の空売り残高
- 踏み上げリスクの検出

### 信用取引残高
- 買残・売残の推移
- 信用倍率
- 追証発生リスク

### EDINET大量保有報告書
- 5%以上保有の報告
- 保有目的の変更
- アクティビストの動き

## 分析ロジック

### 外国人売買フロー分析
1. 週次データを取得
2. 4週間のトレンドを算出
3. 買い越し/売り越しの加速・減速を判定
4. ニュースアナリストに「外国人は買い越し加速中」等のコンテキストを提供

### 空売り残高分析
1. 空売り比率が40%超 → 過度な弱気（逆張りシグナル）
2. 空売り比率が急増 → ヘッジファンドの仕掛け
3. 空売り残高 × 出来高 = 踏み上げまでの日数

## 統合方法
NewsAnalystのコンテキストに以下を追加:
```python
context["smart_money"] = {
    "foreign_flow": jpx_flows.get_investor_flows(),
    "short_positions": jpx_shorts.get_short_selling_ratio(),
    "margin_balance": jpx_margin.get_margin_balance(),
}
```
