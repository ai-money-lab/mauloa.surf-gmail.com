# CITS 本質設計書

## 1. システム概要

CITS (Claude Intelligence Trading System) は、TradingAgentsフレームワークをベースに
日本株特化のマルチエージェント取引システムである。

### コアコンセプト
- **箱**: TradingAgentsの実証済みアーキテクチャ（5段階パイプライン）
- **中身**: CITS独自の日本株特化要素（発言者トラッカー、売買動向分析等）

## 2. 5段階パイプライン

### Stage I: アナリストチーム（並行実行）
| アナリスト | 担当 | LLM |
|---|---|---|
| ファンダメンタル | 決算・財務・インサイダー | Sonnet (quick_think) |
| センチメント | SNS・市場心理 | Sonnet (quick_think) |
| ニュース | ニュース・マクロ・発言者 | Sonnet (quick_think) |
| テクニカル | 価格・出来高・指標 | Sonnet (quick_think) |

### Stage II: リサーチチーム（Bull vs Bear ディベート）
- Bullリサーチャーが買い側の論拠を構築
- Bearリサーチャーが売り側の論拠を構築
- 2ラウンドのディベートで論点を精査（3ラウンド以上は精度向上なし）
- Opus (deep_think) がジャッジ

### Stage III: トレーダー
- ディベート結果 + 過去データから最終判断
- buy / sell / hold の決定
- Opus (deep_think)

### Stage IV: リスク管理
- ポートフォリオリスク評価
- 市場ボラティリティチェック
- サーキットブレーカー確認
- 危険と判断したら取引を却下
- Opus (deep_think)

### Stage V: ファンドマネージャー
- 最終承認・執行権限
- 承認されたら注文を執行
- Opus (deep_think)

## 3. データソース

### 市場データ
- yfinance: ^N225, ^TOPX, 個別銘柄 (7203.T等)
- J-Quants API: 東証公式データ

### ニュース・センチメント
- 日経電子版RSS
- ロイター日本語版
- FOMC/BOJ声明文

### 独自データ
- EDINET: 大量保有報告書
- JPX: 投資部門別売買動向
- JPX: 空売り残高
- JPX: 信用取引残高

## 4. レイテンシーアービトラージ戦略

Polymarketボットの手法を応用:
- HFTのヘッドライン反応: ~0.1秒
- Claudeの意味理解: ~3秒
- 機関投資家の判断: 5-30分

CITSは「3秒 vs 5-30分」のギャップを狙う（分単位のアービトラージ）。

## 5. リスク管理ルール

### サーキットブレーカー
- 日次損失: 5万円超で停止
- 連続損失: 3回で停止
- 日次取引数: 10回で停止
- 高ボラティリティ: ポジション縮小

### ペーパートレード移行条件
以下を全て満たした場合のみ実弾投入:
- 勝率 55%以上
- プロフィットファクター 1.3以上
- 最大ドローダウン 10%以内
- 月間リターンがプラス

### 初期資金
- 10万円でマイクロ先物2枚から開始

## 6. 戦略の動的重み配分

3戦略を同時運用し、直近5回の勝率で重み調整:
1. 発言スキャルピング
2. 両建てアービトラージ
3. ドリフト追従

勝っている戦略に多く配分、負けている戦略を縮小。
