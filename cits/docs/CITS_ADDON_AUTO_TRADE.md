# CITS アドオン: 自動取引

## 概要
パイプラインの判断結果を自動的にkabuステーションAPIで発注する。
ペーパートレードで十分な実績を確認した後に有効化する。

## 発注フロー

```
ファンドマネージャー承認
  ↓
サーキットブレーカーチェック
  ↓ (通過)
ポジションサイジング
  ↓
kabuステーションAPI発注
  ↓
ソフトウェアOCO設定（TP/SL）
  ↓
モニタリング開始
  ↓
TP/SLヒット → 決済 → 結果記録
```

## kabuステーションAPI連携

### 前提条件
- kabuステーションがローカルPCで起動していること
- API: http://localhost:18080
- au kabucom証券の口座が必要

### 対応商品
- 日経225マイクロ先物（最小単位）
- 個別株（東証）

### 注文タイプ
- 成行注文（即時約定）
- 指値注文
- ソフトウェアOCO（TP=ソフト監視、SL=逆指値）

## ソフトウェアOCO

kabuステーションはネイティブOCOをサポートしていないため、
ソフトウェアで実装:

1. エントリー注文を発注
2. SLは逆指値注文として実際に発注
3. TPはソフトウェアで価格を監視
4. TPに到達 → 成行決済注文 + SL逆指値をキャンセル
5. SLにヒット → SL逆指値が約定 → TPモニタリング停止

## 安全装置

### 実弾移行条件
- ペーパートレード1ヶ月以上
- 勝率55%以上
- プロフィットファクター1.3以上
- 最大ドローダウン10%以内
- 月間リターンがプラス

### 日次リスク制限
- 日次最大損失: 5万円
- 連続損失: 3回で停止
- 日次最大取引数: 10回
- 高ボラティリティ時: ポジション縮小

### 初期資金
- 10万円（マイクロ先物2枚）
- 段階的に増額（実績に応じて）
