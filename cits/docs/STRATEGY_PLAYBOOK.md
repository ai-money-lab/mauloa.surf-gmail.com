# CITS 戦術プレイブック — 「今日の予想が今日のチャートに出る」手法

## 基本原則

**データがすべて。** LLMの「考え」ではなく、統計的に検証された定量シグナルで判断する。
以下は学術論文・プロファンドの実証研究から抽出した、**同日中に予測→検証が完結する手法**のみ。

---

## Tier 1: 勝率が高く、公開データで実装可能

### 1. イントラデイ・モメンタム（最初の30分→最後の30分）
```
シグナル: 前日終値→今日9:30の30分リターンの符号が、
         14:30→15:00の最後の30分リターンを予測する
勝率:    Sharpe 1.08（年率リターン6.67%、標準偏差6.19%）
R²:      1.6%（通常）→ 3.3%（高ボラ日）
強化条件: 出来高急増日、VIX高日、マクロニュース日に効果倍増
論文:    Gao, Han, Li, Zhou (JFE 2018)
必要データ: 30分足OHLCV
データソース: kabuステーションAPI（PUSH）で自前構築
```
**実装方針:** 9:30時点の30分リターンを計算。符号がプラスなら14:30にロング、マイナスならショート。15:00クローズ。

### 2. オーバーナイト・リバーサル（CO-OC戦略）
```
シグナル: 前日終値→今日始値（overnight return）が大きくマイナスの銘柄を買い、
         大きくプラスの銘柄を売る。場中（intraday）でリバーサルする
勝率:    バックテストSharpe 5.5-10.0（学術）、現実的には1-2
注意:    執行タイミング問題あり（始値で同時にエントリーする困難さ）
         1分遅延でリターンが0.29%→0.11%に低下
論文:    Della Corte & Kosowski; Liu et al. (SSRN)
         日本市場でも確認済み（週次リバーサルスプレッド -0.18%）
必要データ: 前日終値 + 当日始値
データソース: kabuステーションAPI or yfinance（日足）
```
**実装方針:** 寄り前にウォッチリスト全銘柄のギャップを計算。ギャップ率でランキング。上位ショート/下位ロング。ただし執行遅延に極めて敏感。

### 3. オープニングレンジ・ブレイクアウト（ORB 60分）
```
シグナル: 最初の60分間の高値/安値をブレイクした方向にエントリー
勝率:    89.4%（60分ORB）、Profit Factor 1.44
         30分ORBは63%だがリワード/リスク比0.71で微妙
強化条件: トレンド方向フィルター併用で大幅改善（+450%）
有効時間: 10:00-14:00に最もエッジあり。14:00以降は急速に減衰
必要データ: 分足 or 5分足OHLCV
データソース: kabuステーションAPI（PUSH → 自前でバー構築）
```
**実装方針:** 9:00-10:00の高値安値を記録。ブレイク方向にエントリー。14:00までにクローズ。トレンドフィルター（前日SMA位置）併用必須。

### 4. 日経VI レジームフィルター（全戦略の上位スイッチ）
```
シグナル: 他の全戦略のON/OFFスイッチとして使用
         日経VI < 20: トレンドフォロー戦略有効
         日経VI 20-25: 通常シグナル適用
         日経VI > 25: ミーンリバージョン戦略有効、サイズ縮小
         日経VI > 35: 全ポジション縮小/停止
効果:    他シグナルのSharpeとCalmar比が大幅改善
必要データ: 日経VI リアルタイム値
データソース: nikkei225jp.com（スクレイピング）or kabuステーション
```

## Tier 2: 日本市場固有のカレンダーエッジ

### 5. SQ週パターン（メジャーSQ月: 3,6,9,12月）
```
シグナル: SQ日（第2金曜）の週は異常にボラタイル
         「魔の水曜日」= SQ週の水曜は弱気バイアス
         SQ当日の寄付は約1兆円の裁定解消で板が荒れる
戦略:    SQ週はポジションサイズ50%に縮小
         魔の水曜日はショートバイアス
         SQ日の寄付は参加しない
必要データ: カレンダー（固定）+ オプションOI
データソース: JPX公開データ、stock-marketdata.com
```

### 6. 権利付最終日ドリフト
```
シグナル: 権利付最終日の約60営業日前から株価がドリフトアップ
         CAR（累積異常リターン）> 5%
         特に非貸借銘柄（空売り制約あり）で強い
戦略:    優待銘柄を60日前にロング → 権利付最終日の前日にクローズ
         権利落ち日はTOPIX -0.69%、日経 -0.68%
論文:    日本証券経済研究所（4,107件、2011-2014）
必要データ: 優待・配当の権利確定日カレンダー
データソース: JPX、各証券会社の優待カレンダー
```

### 7. 月末/四半期末リバランスフロー
```
シグナル: GPIFなど年金基金の四半期リバランスは予測可能
         GPIF推定リバランス額: 約$16B/四半期
         株式が上昇した四半期末 → 年金は株式を売る（リバランス）
         株式が下落した四半期末 → 年金は株式を買う
戦略:    月末/四半期末の最後3営業日にリバランス方向と逆のポジション
必要データ: 直近の株式/債券リターン差 + カレンダー
データソース: 自前計算可能
```

### 8. BOJ会合日パターン
```
シグナル: 反応は2段階 — ①金利決定 → ②フォワードガイダンスのトーン
         USD/JPYが先行、次にJGB利回り、最後に株式
         ウィップソーリスク高（決定は予想通りだがガイダンスがサプライズ）
戦略:    会合日は新規ポジション取らない
         結果発表後、USD/JPY方向を確認してからエントリー
必要データ: BOJ会合スケジュール（年次公開）
データソース: BOJ公式サイト
```

## Tier 3: 寄り前クロスマーケットシグナル（コンテキスト強化）

### 9. 寄り前3点セット（CME夜間 + USD/JPY + VIX）
```
シグナル: 以下3つの方向一致で当日の方向予測精度が上がる
         ① CME日経225先物の夜間変動（対前日大引け）
         ② USD/JPYの夜間変動（円安=日本株上昇バイアス）
         ③ VIXの終値水準と変動
相関:    USD/JPY ↔ 日経225の20日ローリング相関 = 0.81-0.91
注意:    相関はレジーム依存。キャリートレード巻き戻し時に崩壊
必要データ: CME先物、FXレート、VIX
データソース: Yahoo Finance（^NKD, USDJPY=X, ^VIX）、FRED API
```

### 10. 板情報オーダーフローインバランス（OFI）
```
シグナル: 寄り前（8:00-9:00）の注文インバランスが日中方向を予測
         OFIは日経225先物イントラデイリターンの90%以上を説明
注意:    統計的予測力は極めて高いが、コスト控除後の利益は困難
         （Yamamoto 2012: buy-and-holdに勝てない）
必要データ: Level 2板情報（10レベル）
データソース: kabuステーションAPI（PUSH、10本値）
```

### kabuステーションAPIが中核

現在のCITSはyfinance（日足、15分遅延）に依存。これを**kabuステーションAPI**に置き換えることで:
- リアルタイム板情報（10本値）
- ティックデータ（歩み値）
- VWAP
- 先物/オプション
- FXレート

すべて**無料**で取得可能。ただし三菱UFJ eスマート証券の口座が必要。

## 検証プロトコル

**「今日立てた予想が今日のチャートに反映されてた」を毎日検証する:**

```python
# 毎日の検証ループ
1. 寄り前: 全シグナルのスコアを記録（予測方向 + 確信度）
2. 場中:   ORB・モメンタムシグナルを記録
3. 大引け後: 実際のリターンと予測を照合
4. DB記録:  signal_name, predicted_direction, actual_return, win/loss
5. 週次:    各シグナルの勝率・Sharpe・Profit Factorを自動計算
6. 月次:    勝率55%未満のシグナルは無効化
```

**これがWinRateEngineの本来の使い方。** 現在は取引結果だけ記録しているが、
**シグナル単位の勝率追跡**に拡張すべき。
