# 神聖デプロイ

安全確認を全て通過した上でデプロイを実行する。一切の妥協なし。

## 引数
- `$ARGUMENTS`: デプロイ先指定（例: "render", "docker"）
- 引数なしでデフォルト（Render.com）

## 実行手順

1. **Pre-flight Check（飛行前点検）**:
   - [ ] `ruff check` — lintエラーゼロを確認
   - [ ] `pytest` — 全テストパスを確認
   - [ ] `git status` — コミット漏れがないか確認
   - [ ] `config/config.yaml` — 設定値の妥当性確認
   - [ ] セキュリティ — ハードコードされたシークレットがないか確認
   - 1つでも失敗したらデプロイを中止し、問題を報告

2. **デプロイ準備**:
   - 全変更をコミット（未コミットがあれば）
   - ブランチをリモートにプッシュ

3. **デプロイ実行**:
   - **Render.com**: `render.yaml` の設定を確認し、デプロイ手順を案内
   - **Docker**: `docker compose -f inquiry_bot/docker-compose.yaml up -d --build`

4. **Post-deploy Check（デプロイ後確認）**:
   - ヘルスチェック実行（Botが応答するか）
   - ログに異常がないか確認

5. **出力**:
   ```
   ═══════════════════════════════════════════════
    DIVINE DEPLOY — デプロイ結果
   ═══════════════════════════════════════════════

   Pre-flight:  全{n}項目パス
   デプロイ先:  {target}
   ステータス:  {SUCCESS/FAILED}

   {デプロイ後の確認結果}
   ═══════════════════════════════════════════════
   ```
