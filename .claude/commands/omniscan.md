# 全システム品質オムニスキャン

コードベース全体を神の目で走査し、バグ・品質問題・改善点を洗い出す。

## 実行手順

1. **Lint & 静的解析**:
   ```bash
   ruff check inquiry_bot/ core/ system_a/ system_b/ system_c/ system_d/ --select E,W,F --ignore E501
   ```
   エラーを分類・重要度順にリスト化

2. **テスト実行**:
   ```bash
   PYTHONPATH=. python -m pytest tests/ -v --tb=short
   ```
   失敗テストがあれば原因を分析

3. **設定整合性チェック**:
   - `config/config.yaml` の全項目が各システムで正しく参照されているか
   - `config/.env.example` に記載のある環境変数が実際に使われているか
   - `requirements.txt` に不足/未使用パッケージがないか

4. **セキュリティスキャン**:
   - ハードコードされたAPIキー/シークレットがないか全ファイル検索
   - `.env` ファイルが `.gitignore` に含まれているか確認
   - 外部API呼び出しのエラーハンドリング漏れチェック

5. **品質ゲート検証**:
   - `core/quality_checker.py` の閾値設定が `config/config.yaml` と一致しているか
   - 品質ログ（`data/quality_logs/`）に閾値未満の通過がないか

6. **依存関係チェック**:
   - Pythonパッケージの脆弱性チェック（pip auditがあれば）
   - Node.jsパッケージの `npm audit` 結果

## 出力フォーマット

```
═══════════════════════════════════════════════
 OMNISCAN RESULTS — 全システム品質レポート
═══════════════════════════════════════════════

 [CRITICAL] {件数}件 — 即座に対応必要
 [WARNING]  {件数}件 — 早めに対応推奨
 [INFO]     {件数}件 — 改善提案

─────────────────────────────────────────────
{カテゴリ別の詳細リスト}
═══════════════════════════════════════════════
```

重要度が高い順に報告し、各項目に修正案を添える。
