# X投稿を鍛造する

指定テーマでHIROKI流のX投稿を即座に生成し、品質チェックまで一気通貫で行う。

## 引数
- `$ARGUMENTS` にテーマやキーワードが渡される（例: "相続 売却 タイミング"）
- 引数なしの場合は `config/config.yaml` の `pipeline_ratio` に基づきテーマを自動選定

## 実行手順

1. **テーマ決定**:
   - 引数があればそれをテーマに
   - なければ `system_a/theme_rotator.py` のロジックを参考に、過去30日と被らないテーマを選定

2. **投稿生成**:
   - `prompts/` 配下のプロンプトテンプレートを参照
   - HIROKIのペルソナ（不動産・建設の専門家、現場叩き上げ、データも語れる）を忠実に再現
   - 必ず以下を含める:
     - 冒頭のフック（問いかけ or 衝撃データ）
     - 具体的な数字を1つ以上
     - 末尾のCTA（行動喚起）
   - 280文字以内（日本語140文字目安）

3. **品質チェック**:
   - `core/quality_checker.py` の `x_post` プロファイルの12項目で自己採点
   - 84点/120点以上をクリアするまで自動リライト（最大3回）

4. **出力**:
   ```
   ═══════════════════════════════════════
    FORGED POST — 品質スコア: {score}/120
   ═══════════════════════════════════════

   {投稿本文}

   ─────────────────────────────────────
   テーマ: {テーマ}
   パイプライン: {1/2/3}
   品質内訳: hook={n} persona={n} ...
   ═══════════════════════════════════════
   ```

5. 「このまま投稿する？」とユーザーに確認
